    기출서술

    가운데 오각형은 홀짝 규칙에서 외부, 접기 횟수 규칙에서 내부.

    • 홀짝 규칙: 점에서 한쪽으로 반직선을 긋고 경계와 만난 횟수를 센다. 홀수면 내부, 짝수면 외부. 구현이 간단하다.
    • 접기 횟수 규칙: 꼭짓점 순서로 에지 방향을 정하고, 반직선이 아래로 가는 에지와 만나면 +1, 위로 가는 에지면 −1을 더한다. 합이 0이 아니면 내부, 0이면 외부. 에지 방향으로 내부를 자유롭게 정할 수 있어 정교한 드로잉 소프트웨어에서 쓴다.
    • 별 가운데: 반직선이 경계와 2번 만난다. 홀짝은 짝수라 외부. 두 변이 같은 방향이라 합이 2이므로 접기 횟수는 내부.

    • 원인: 아날로그 영상을 디지털 픽셀로 바꾸는 샘플링 오차. 저해상도에서 두드러지고, 선이 움직이면 위치가 튀어 보인다.
    • 해상도 높이기: 효과는 있지만 물리적 한계가 있다.
    • 경계 혼합: 경계 픽셀을 물체 색과 배경 색의 중간으로 칠한다. 선, 다각형 채우기, 문자에 적용.
    • SSAA: 한 픽셀을 여러 샘플로 나눠 그린 뒤, 도형이 덮은 비율만큼 명암을 정해 원래 해상도로 줄인다.
    • MSAA: SSAA를 효율화. 폴리곤 외곽선이 지나는 곳만 여러 번 샘플링한다.
    • FXAA, MLAA: 렌더링 후 주변 픽셀 밝기 차이를 보고 색을 섞는 후처리.

    유형보존변환

    이동이 선형이 아닌 이유: 선형 변환은 T(u + v) = T(u) + T(v), T(cu) = cT(u)를 만족해야 하고 원점은 원점으로 가야 한다. 이동은 T(0) = (tx, ty) ≠ 0이고, T(u + v) = u + v + t 인데 T(u) + T(v) = u + v + 2t라서 성립하지 않는다.

    단답

    결합법칙은 성립, 교환법칙은 성립하지 않는다.

    • 같은 종류끼리는 교환 가능: 이동끼리 T(t1)T(t2) = T(t1 + t2), 회전끼리 각도 더하기, 신축끼리 배율 곱하기.
    • 균등 신축과 회전도 순서를 바꿔도 같다.
    • 이동과 회전은 다르다. 예: 점 (1, 0)에 회전 90° 후 x로 1 이동하면 (1, 1), 이동 후 회전하면 (0, 2).

  1. D1

    윈도우 (0, 0)~(20, 10)을 뷰포트 (100, 50)~(300, 250)으로 변환할 때 점 (5, 4)와 (15, 8)의 뷰포트 좌표를 구하시오. 그리고 변환 후 도형 모양이 어떻게 되는지 쓰시오.

    기출계산

    (5, 4) → (150, 130), (15, 8) → (250, 210). sx ≠ sy라 세로로 늘어나 모양이 찌그러진다.

    sx = (xvR − xvL)/(xwR − xwL) = (300 − 100)/(20 − 0) = 200/20 = 10

    sy = (yvT − yvB)/(ywT − ywB) = (250 − 50)/(10 − 0) = 200/10 = 20

    (5, 4): xv = 100 + (5 − 0)·10 = 150, yv = 50 + (4 − 0)·20 = 130

    (15, 8): xv = 100 + 15·10 = 250, yv = 50 + 8·20 = 210

    행렬로 쓰면 T(xvL, yvB) · S(sx, sy) · T(−xwL, −ywB). 윈도우 왼쪽 아래를 원점으로 옮기고, 배율을 곱하고, 뷰포트 왼쪽 아래로 옮긴다.

    윈도우와 뷰포트의 가로세로 비율이 다르면 sx ≠ sy가 되어 왜곡된다. 비율이 같아야 모양이 유지된다.

  2. D2

    윈도우와 뷰포트의 정의를 쓰고, 뷰포트를 고정했을 때 확대 효과와 패닝 효과를 내려면 윈도우를 어떻게 바꿔야 하는지 쓰시오.

    단답
    • 윈도우: 표시하려고 선택한 세계 좌표 영역. 무엇을 보여줄지.
    • 뷰포트: 윈도우가 사상되는 출력 장치 영역. 어디에 보여줄지.
    • 확대: 윈도우를 작게 → 좁은 영역이 같은 뷰포트에 꽉 차서 크게 보인다. 축소는 윈도우를 크게.
    • 패닝: 윈도우 크기는 그대로 두고 위치만 평행 이동.
    • 멀티 뷰포트: 뷰포트 여러 개로 한 화면에 여러 장면.
    • 월드 좌표 클리핑은 윈도우 밖을 먼저 지우고 매핑, 뷰포트 클리핑은 전부 매핑 후 뷰포트 밖을 지운다. 결과 화면은 같다.
  3. D3

    윈도우 0 ≤ x ≤ 10, 0 ≤ y ≤ 10에 대해 Cohen-Sutherland 알고리즘을 적용하시오.(a) P1(−4, −2), P2(6, 13) · (b) Q1(−3, 12), Q2(4, 15) · (c) R1(2, 3), R2(8, 6). 영역 코드는 위 아래 오른 왼 순서 4비트.

    기출계산

    (a) (0, 4)~(4, 10) · (b) 버림 · (c) 그대로 그림

    (a) P1(−4, −2), P2(6, 13)

    P1: 왼쪽, 아래 → 0101 · P2: 위 → 1000 · AND = 0000 → 교차점 계산

    m = (13 − (−2))/(6 − (−4)) = 15/10 = 1.5

    P1을 왼쪽 경계 x = 0에: y = −2 + 1.5·(0 + 4) = 4 → (0, 4), 코드 0000

    P2를 위 경계 y = 10에: x = 6 + (10 − 13)/1.5 = 6 − 2 = 4 → (4, 10), 코드 0000

    결과 (0, 4)~(4, 10)

    (b) Q1(−3, 12), Q2(4, 15)

    Q1: 위, 왼쪽 → 1001 · Q2: 위 → 1000

    AND = 1000 ≠ 0 → 둘 다 위쪽 바깥이라 완전히 밖, 버림

    (c) R1(2, 3), R2(8, 6)

    둘 다 0000 → 완전히 안, 그대로 그림

    교차점 공식: 수직 경계 y = y1 + m(x − x1), 수평 경계 x = x1 + (y − y1)/m. 교차점을 구한 뒤 코드를 다시 확인하는 게 중요해. 아직 0000이 아니면 한 번 더 자른다.

  4. D4

    윈도우 (0, 0)~(10, 10)에 대해 Liang-Barsky 알고리즘으로 선분 P1(−5, 2), P2(15, 12)를 클리핑하시오. pk, qk, uk를 모두 구하시오.

    기출계산

    ustart = 0.25, uend = 0.75 → (0, 4.5)~(10, 9.5)

    dx = 15 − (−5) = 20, dy = 12 − 2 = 10

    k경계pkqkuk = qk/pk구분
    1left−dx = −20x1 − xmin = −50.25p < 0 start
    2rightdx = 20xmax − x1 = 150.75p > 0 end
    3bottom−dy = −10y1 − ymin = 2−0.2p < 0 start
    4topdy = 10ymax − y1 = 80.8p > 0 end

    ustart = max(0, 0.25, −0.2) = 0.25

    uend = min(1, 0.75, 0.8) = 0.75

    ustart < uend 이므로 그린다

    새 P1 = (−5 + 0.25·20, 2 + 0.25·10) = (0, 4.5)

    새 P2 = (−5 + 0.75·20, 2 + 0.75·10) = (10, 9.5)

  5. D5

    같은 윈도우 (0, 0)~(10, 10)에서 선분 P1(−2, 8), P2(4, 16)을 Liang-Barsky로 판단하시오.

    기출계산

    ustart = 1/3 > uend = 0.25 이므로 버림

    dx = 6, dy = 8

    k1: p = −6, q = −2 − 0 = −2, u = 1/3 (start)

    k2: p = 6, q = 10 − (−2) = 12, u = 2 (end)

    k3: p = −8, q = 8 − 0 = 8, u = −1 (start)

    k4: p = 8, q = 10 − 8 = 2, u = 0.25 (end)

    ustart = max(0, 1/3, −1) = 1/3, uend = min(1, 2, 0.25) = 0.25

    uend < ustart → 윈도우와 겹치는 구간이 없다

    검산: x = 0일 때 y = 8 + (8/6)·2 ≈ 10.67 > 10. 왼쪽 경계에 닿기 전에 이미 위로 나가 있어서 윈도우 모서리 위를 지나간다.

  6. D6

    Sutherland-Hodgman 알고리즘의 네 가지 경우를 쓰고, 삼각형 A(−2, 2), B(4, 2), C(4, 6)을 왼쪽 경계 x = 0으로 클리핑한 결과 꼭짓점을 구하시오.

    기출계산

    결과 사각형 (0, 2), (4, 2), (4, 6), (0, 3.33)

    변 시작 → 끝출력
    안 → 안끝점
    안 → 밖교차점
    밖 → 밖없음
    밖 → 안교차점, 끝점

    x ≥ 0이 안쪽. A는 밖, B와 C는 안

    A → B 밖 → 안: 교차점 (0, 2), 끝점 B(4, 2)

    B → C 안 → 안: 끝점 C(4, 6)

    C → A 안 → 밖: 교차점. 기울기 (2 − 6)/(−2 − 4) = 2/3, x = 0에서 y = 6 + (2/3)(0 − 4) = 10/3 ≈ 3.33 → (0, 3.33)

    실제로는 왼쪽, 오른쪽, 아래, 위 네 경계에 대해 이 과정을 차례로 반복한다. 오목 다각형이 잘려서 여러 조각이 생기면 Weiler-Atherton을 쓴다. 꼭짓점을 시계 방향으로 따라가다 외부에서 내부로 들어가면 다각형 경계를, 내부에서 외부로 나가면 윈도우 경계를 따라간다.

  7. D7

    Cohen-Sutherland와 Liang-Barsky를 비교하시오. Liang-Barsky에서 pk = 0일 때의 의미도 쓰시오.

    서술
    Cohen-SutherlandLiang-Barsky
    방법영역 코드매개변수 방정식
    핵심 연산비트 연산 + 교차점 계산부등식 + u 계산
    특징이해하기 쉬움수학적으로 효율적, 교차점을 반복해서 구하지 않음

    pk = 0: 선분이 그 경계와 평행. qk < 0이면 경계 바깥에 있으므로 버리고, qk ≥ 0이면 다른 경계로 판단한다.

    pk < 0은 밖에서 안으로 들어가는 경계라 ustart 후보, pk > 0은 안에서 밖으로 나가는 경계라 uend 후보.

5장 · 조명 모델과 쉐이딩

공식 세 개와 쉐이딩 세 개를 구분하면 끝.

  1. E1

    물체의 한 점이 보이는 색과 밝기를 결정하는 요소 네 가지를 쓰고, 빛이 물체 표면에서 일으키는 현상을 쓰시오.

    기출서술
    • 광원의 특성: 빛의 색, 세기
    • 광원의 위치: 표면과 광원의 방향, 거리. 점광원은 거리 제곱에 반비례
    • 물체의 특성: 고유 색, 산란반사 특성, 거울반사 특성, 광택 정도
    • 관찰자의 위치: 특히 거울반사에 영향
    • 표면 현상: 흡수, 반사 즉 산란반사와 거울반사, 투명 물체의 굴절과 투과. 우리가 보는 색은 주로 반사된 빛이다.
  2. E2

    주변 조명, 산란반사, 거울반사를 비교하시오. 관찰자 위치의 영향과 예시 물체를 포함하시오.

    기출서술
    주변 조명산란반사거울반사
    내용간접광을 단순화한 기본 밝기여러 방향으로 고르게 반사특정 방향으로 강하게 반사
    관찰자 영향없음작음큼
    공식Ka·Ia(Ip/d)·Kd·(N·L)(Ip/d)·Ks·(V·R)ⁿ
    예완전히 어두워지는 것 방지종이, 나무, 무광택금속, 유리, 광택
  3. E3

    표면 법선 N = (0, 0, 1), 표면에서 광원 방향 L은 표면 점에서 (3, 0, 4) 쪽이다. Ka = 0.2, Ia = 0.5, Ip = 10, d = 10, Kd = 0.6일 때 Lambert 조명 모델로 밝기를 구하시오.

    계산

    I = 0.58

    L은 단위벡터로: |(3, 0, 4)| = 5 → L = (0.6, 0, 0.8)

    N·L = 0·0.6 + 0·0 + 1·0.8 = 0.8 → cosθ = 0.8

    I = Ka·Ia + (Ip/d)·Kd·(N·L) = 0.2·0.5 + (10/10)·0.6·0.8 = 0.1 + 0.48 = 0.58

    램버트 코사인 법칙: 표면이 받는 빛은 cosθ = N·L에 비례. 반드시 단위벡터로 바꾼 뒤 내적해야 한다. N·L이 음수면 0으로 처리.

  4. E4

    E3 조건에 관찰자 방향 V = (0, 0, 1), Ks = 0.5, n = 4를 추가한다. 반사 방향 R과 Phong 조명 모델의 전체 밝기를 구하시오.R = 2(N·L)N − L

    계산

    R = (−0.6, 0, 0.8), I ≈ 0.785

    R = 2·0.8·(0, 0, 1) − (0.6, 0, 0.8) = (0, 0, 1.6) − (0.6, 0, 0.8) = (−0.6, 0, 0.8)

    V·R = 0·(−0.6) + 0·0 + 1·0.8 = 0.8

    (V·R)ⁿ = 0.8⁴ = 0.4096

    I = Ka·Ia + (Ip/d)·[Kd(N·L) + Ks(V·R)ⁿ]

    = 0.1 + 1·(0.6·0.8 + 0.5·0.4096) = 0.1 + 0.48 + 0.2048 = 0.7848

    n이 커지면 0.8⁸ ≈ 0.168, 0.8³² ≈ 0.0008로 급격히 줄어든다. 광택이 큰 표면일수록 n이 크고 하이라이트가 좁다.

  5. E5

    삼각형 P1(5, 10) 밝기 1.0, P2(0, 0) 밝기 0.2, P3(10, 0) 밝기 0.6이 있다. Gouraud 쉐이딩으로 주사선 y = 4 위의 점 (5, 4)의 밝기를 구하시오.

    계산

    Ip = 0.64

    1. 변 P1P2 위의 점 4

    I4 = (y4 − y2)/(y1 − y2)·I1 + (y1 − y4)/(y1 − y2)·I2 = (4/10)·1.0 + (6/10)·0.2 = 0.4 + 0.12 = 0.52

    x4 = 0 + (5 − 0)·(4/10) = 2

    2. 변 P1P3 위의 점 5

    I5 = (4/10)·1.0 + (6/10)·0.6 = 0.4 + 0.36 = 0.76

    x5 = 10 + (5 − 10)·(4/10) = 8

    3. 주사선 위 xp = 5

    Ip = (x5 − xp)/(x5 − x4)·I4 + (xp − x4)/(x5 − x4)·I5 = (3/6)·0.52 + (3/6)·0.76 = 0.26 + 0.38 = 0.64

    가까운 끝점 쪽 값을 더 많이 반영한다. Phong 쉐이딩은 같은 식으로 밝기 대신 법선 벡터를 보간한다.

  6. E6

    균일, Gouraud, Phong 쉐이딩을 보간하는 대상, 조명 계산 위치, 장단점으로 비교하시오. Mach Band 효과도 설명하시오.

    서술
    균일GouraudPhong
    보간없음, 면당 한 색정점 밝기정점 법선
    계산 위치면마다 한 번정점에서각 픽셀에서
    장점간단, 다면체엔 양호밝기 불연속 제거하이라이트가 실감
    단점경계 계단, 현실감 낮음하이라이트 변칙, Mach Band계산량 많음

    Mach Band: 밝기가 꺾이는 경계에서 실제보다 더 밝거나 어두운 띠가 보이는 착시. Gouraud에서 두드러지고 Phong 쉐이딩이 크게 줄인다.

    Phong 조명 모델은 밝기 공식, Phong 쉐이딩은 법선 보간 방법. 이름이 같아도 다른 것.

  7. E7

    광선 추적법의 밝기 구성 요소와 종료 조건 네 가지, 장단점을 쓰시오.

    서술

    I = Iamb + Idiff + Ispec + Irefl + Irefr. 주변광, 산란반사, 거울반사, 반사광, 굴절광의 합.

    1. 광선이 어떤 물체와도 만나지 않음
    2. 광선이 광원과 만남
    3. 반사와 굴절 횟수가 정한 횟수보다 많아짐
    4. 반사와 굴절로 빛의 세기가 임계값 이하가 됨

    장점: 은면 제거와 그림자를 동시에 처리하고 매우 사실적. 단점: 계산 시간이 많이 든다.

  8. E8

    Phong 조명 모델에서 광원이 매우 멀리 있을 때와 관찰자가 매우 멀리 있을 때 각각 어떤 항이 일정해지는지 쓰시오.

    단답

    광원이 멀면 N·L이, 관찰자가 멀면 V·R이 표면 위치와 상관없이 일정해진다.

    평면 위 어느 점에서 봐도 광원 방향 L과 관찰자 방향 V가 거의 같아지기 때문이다. 그래서 계산을 크게 줄일 수 있다.

    브레즌햄 선에서 p ≥ 0일 때 다음 점과 p에 더하는 값은?

    기출 주제단답

    다음 점 (x+1, y+1), p에 2(Δy − Δx)를 더함

    p < 0이면 (x+1, y), p에 2Δy를 더함.

  11. S11

    브레즌햄 원 알고리즘의 첫 판단 매개변수는?

    기출 주제단답

    p1 = 3 − 2r

  12. S12

    브레즌햄 원 알고리즘이 원 전체가 아니라 1/8만 계산하는 이유는?

    기출 주제단답

    원은 8방향 대칭이라 나머지 7구간은 (±x, ±y), (±y, ±x)로 얻을 수 있기 때문

  13. S13

    홀짝 규칙에서 점에서 그은 반직선이 경계와 3번 만나면 내부인가 외부인가?

    기출 주제단답

    내부

    홀수면 내부, 짝수면 외부.

  14. S14

    접기 횟수 규칙에서 만난 변들의 방향 합이 0이면 내부인가 외부인가?

    기출 주제단답

    외부

    0이 아니면 내부.

  15. S15

    홀짝 규칙과 접기 횟수 규칙 중 변의 방향을 고려하는 것은?

    기출 주제단답

    접기 횟수 규칙(Non-Zero Winding)

    방향은 꼭짓점이 주어진 순서로 정해진다.

  16. S16

    Flood Fill은 어떤 조건이면 계속 칠하는가?

    단답

    현재 픽셀이 원래 영역의 색과 같을 때

    Boundary Fill은 경계색을 만나면 멈춘다.

  17. S17

    경계를 8방향 연결로 그렸을 때 내부는 몇 방향 연결로 채워야 하는가?

    단답

    4방향

    8방향으로 채우면 대각선 틈으로 새어 나간다.

  18. S18

    y-x 주사선 알고리즘에서 현재 주사선과 만나는 에지만 모아 둔 목록의 이름은?

    단답

    AEL, Active Edge List

    전체 에지 목록은 EL, Edge List.

  19. S19

    한 픽셀을 여러 개로 나눠 그린 뒤 덮인 비율로 명암을 정하는 안티앨리어싱 기법은?

    기출 주제단답

    SSAA, 수퍼샘플링

  20. S20

    폴리곤 외곽선이 지나는 곳만 여러 번 샘플링하는 안티앨리어싱 기법은?

    기출 주제단답

    MSAA, 멀티샘플링

    FXAA, MLAA는 렌더링 후 후처리 방식.

3장 2D 변환

  1. S21

    2D 변환을 3×3 행렬로 쓰기 위해 (x, y)를 어떻게 확장하는가? 그 좌표계 이름은?

    기출 주제단답

    (x, y, 1), 동차좌표계

    이동까지 행렬 곱으로 통일할 수 있다.

  2. S22

    P' = T · R · P 에서 점에 먼저 적용되는 변환은?

    기출 주제단답

    R(회전)

    점에 가까운 오른쪽 행렬부터 적용.

  3. S23

    임의의 점 (x0, y0)를 기준으로 회전하는 합성 변환식은?

    기출 주제단답

    T(x0, y0) · R(θ) · T(−x0, −y0)

    기준점을 원점으로 옮기고, 돌리고, 되돌린다.

  4. S24

    변환 행렬 곱에서 성립하는 법칙과 성립하지 않는 법칙은?

    기출 주제단답

    결합법칙은 성립, 교환법칙은 성립하지 않음

  5. S25

    x축 반사를 하면 (x, y)는 어떻게 되는가?

    기출 주제단답

    (x, −y)

  6. S26

    y = x 직선에 대해 반사하면 (x, y)는 어떻게 되는가?

    기출 주제단답

    (y, x)

    y = −x 반사는 (−y, −x).

  7. S27

    원점에 대해 반사하면 (x, y)는 어떻게 되는가?

    기출 주제단답

    (−x, −y)

  8. S28

    y = x 반사를 회전과 x축 반사로 나타낸 식은?

    기출 주제단답

    R(45°) · Mx · R(−45°)

    시계 45° 회전, x축 반사, 반시계 45° 회전 순서로 적용.

  9. S29

    y = mx + b 직선에 대한 반사를 만드는 순서는?

    기출 주제단답

    T(0, −b)로 직선을 원점으로 옮기고, R(−θ)로 x축에 맞추고, x축 반사, R(θ), T(0, b)로 되돌림

    θ = arctan m. 합성식 M = T(0, b) · R(θ) · Mx · R(−θ) · T(0, −b)

  10. S30

    x축 방향 밀림 hx를 적용하면 x'과 y'은?

    기출 주제단답

    x' = x + hx·y, y' = y

    고정된 곳에서 멀수록 많이 밀린다.

  11. S31

    y축 방향 밀림 hy를 적용하면 x'과 y'은?

    기출 주제단답

    x' = x, y' = y + hy·x

  12. S32

    신축률 s가 음수이면 크기 변환과 함께 어떤 효과가 생기는가?

    단답

    반사

  13. S33

    크기와 각도를 보존하는 강체 변환에 속하는 변환 두 가지는?

    단답

    이동, 회전

  14. S34

    기본 변환 중 선형 변환이 아닌 것은?

    단답

    이동

    원점이 원점으로 가지 않는다.

  15. S35

    어파인 변환이 보존하는 성질 세 가지는?

    단답

    직선, 길이의 비, 평행성

4장 윈도우, 뷰포트, 클리핑

  1. S36

    윈도우와 뷰포트를 한 마디씩으로 구분하면?

    기출 주제단답

    윈도우는 무엇을 보여줄지(세계 좌표 영역), 뷰포트는 어디에 보여줄지(출력 장치 영역)

  2. S37

    윈도우→뷰포트 변환에서 x 방향 배율 sx의 식은?

    기출 주제단답

    sx = (xvR − xvL) / (xwR − xwL)

    뷰포트 너비 ÷ 윈도우 너비.

  3. S38

    윈도우→뷰포트 변환에서 xv의 식은?

    기출 주제단답

    xv = xvL + (xw − xwL) · sx

  4. S39

    sx와 sy가 다르면 변환 후 도형은 어떻게 되는가?

    기출 주제단답

    가로세로 비율이 바뀌어 찌그러진다

  5. S40

    뷰포트는 그대로 두고 윈도우를 작게 하면 화면은 어떻게 보이는가?

    단답

    확대되어 보인다(zoom-in)

    윈도우를 크기 그대로 평행 이동하면 패닝.

  6. S41

    Cohen-Sutherland 영역 코드는 몇 비트이고 각 비트는 무엇을 뜻하는가?

    기출 주제단답

    4비트. 위, 아래, 오른쪽, 왼쪽 바깥에 있는지

  7. S42

    Cohen-Sutherland에서 양 끝점 코드가 둘 다 0000이면?

    기출 주제단답

    완전히 안쪽, 그대로 그린다

  8. S43

    Cohen-Sutherland에서 양 끝점 코드의 AND가 0이 아니면?

    기출 주제단답

    같은 쪽 바깥이라 완전히 밖, 버린다

  9. S44

    Liang-Barsky에서 pk < 0인 경계는 무엇을 갱신하는가?

    기출 주제단답

    ustart = max(ustart, qk/pk)

    밖에서 안으로 들어가는 경계. pk > 0이면 uend = min(uend, qk/pk).

  10. S45

    Liang-Barsky에서 계산 결과 uend < ustart이면?

    기출 주제단답

    윈도우와 겹치는 부분이 없어서 버린다

  11. S46

    Liang-Barsky에서 pk = 0의 의미는?

    기출 주제단답

    선분이 그 경계와 평행

    qk < 0이면 밖이라 버린다.

  12. S47

    Sutherland-Hodgman에서 변이 안 → 밖일 때 출력하는 점은?

    기출 주제단답

    교차점만

    밖 → 안이면 교차점과 끝점, 안 → 안이면 끝점, 밖 → 밖이면 없음.

  13. S48

    오목 다각형을 잘라 여러 조각이 생길 때 쓰는 다각형 클리핑 알고리즘은?

    기출 주제단답

    Weiler-Atherton

5장 조명과 쉐이딩

  1. S49

    물체의 한 점이 보이는 색과 밝기에 영향을 주는 요소 네 가지는?

    기출 주제단답

    광원의 특성, 광원의 위치, 물체의 특성, 관찰자의 위치

  2. S50

    관찰자 위치에 따라 밝기가 크게 달라지는 반사는?

    기출 주제단답

    거울반사(Specular)

    산란반사는 관찰자 영향이 작다.

  3. S51

    종이나 나무처럼 여러 방향으로 고르게 반사하는 것은?

    기출 주제단답

    산란반사(Diffuse)

  4. S52

    물체가 완전히 어두워지는 것을 막아 주는 조명은?

    기출 주제단답

    주변 조명(Ambient)

    I = Ka · Ia

  5. S53

    램버트 코사인 법칙에서 표면이 받는 빛은 무엇에 비례하는가?

    기출 주제단답

    cosθ = N · L

    N은 법선, L은 광원 방향, 둘 다 단위벡터.

  6. S54

    Phong 거울반사 식에서 n이 크다는 것은 어떤 표면인가?

    광택이 많은 표면, 하이라이트가 좁고 날카로움

  7. S55

    이상적인 점광원의 세기는 거리와 어떤 관계인가?

    기출 주제단답

    거리의 제곱에 반비례

  8. S56

    Gouraud 쉐이딩과 Phong 쉐이딩은 각각 무엇을 보간하는가?

    단답

    Gouraud는 정점 밝기, Phong은 정점 법선

  9. S57

    Gouraud 쉐이딩에서 두드러지는 착시 효과는?

    단답

    Mach Band 효과

  10. S58

    면 하나를 한 색으로 칠하는 쉐이딩은?

    단답

    균일 쉐이딩(Flat, Constant)

  11. S59

    광선추적법의 장점과 단점은?

    단답

    은면 제거와 그림자를 함께 처리하고 사실적이다. 계산 시간이 많다.
