래스터 스캔 방식: 픽셀 단위로 스캔 라인을 따라 한 줄씩 출력, 프레임 버퍼에 저장 후 주기적으로 재생. 이중 프레임 버퍼 사용. 메모리를 많이 쓰고 선에 계단 현상이 생길 수 있음.

점과 선

  • 점: 래스터 장치에서는 픽셀, 기하 공간에서는 좌표 (x, y). 속성은 크기, 명암, 색, 모양.
  • 선: 양 끝점으로 정의. 절대좌표(시작점, 끝점) 또는 상대좌표(시작점, 증가값 Δx Δy).
  • 직선 y = mx + c, m = (y2 − y1)/(x2 − x1), c = y1 − m·x1.

DDA 알고리즘 출제

x 또는 y를 1씩 늘리면서 다른 좌표에 기울기만큼 더하고, 그 값을 반올림해 픽셀을 정한다

기울기한 칸씩 늘리는 쪽다음 픽셀
|m| ≤ 1x(xk + 1, round(yk + m))
|m| > 1y(round(xk + 1/m), yk + 1)
  • 초기화: Δx = xb − xa, Δy = yb − ya, m = Δy/Δx, 시작점 (xa, ya).
  • 특징: 곱셈 없이 실수 덧셈만 반복. 하지만 부동소수 연산이라 정수 연산보다 느리고, 반올림 시간이 걸리며, 오차가 누적될 수 있다.
예) (0, 0)에서 (5, 3): m = 0.6 ≤ 1이라 x를 1씩
y = 0, 0.6, 1.2, 1.8, 2.4, 3.0 → 반올림 0, 1, 1, 2, 2, 3
픽셀 (0,0) (1,1) (2,1) (3,2) (4,2) (5,3)

브레즌햄 선 그리기 출제

0 ≤ m ≤ 1일 때 다음 점은 (x+1, y) 또는 (x+1, y+1) 둘 중 하나. 판단 매개변수 p의 부호로 고른다. 정수 덧셈만 써서 빠르다

  • d1 = 실제 y − yk, d2 = (yk + 1) − 실제 y. pk = Δx(d1 − d2).
  • 초기값: p1 = 2Δy − Δx, C1 = 2Δy, C2 = 2(Δy − Δx)
  • p < 0 → d1 < d2 → 다음 점 (x+1, y), p += C1
  • p ≥ 0 → 다음 점 (x+1, y+1), p += C2
  • 나머지 기울기는 대칭성으로 처리. 응용: 선분 래스터화, 프린터 플로터, LED 매트릭스, 2D 게임 타일 경로와 시야 검사.

브레즌햄 원 그리기 출제

  • 원: (x − xc)² + (y − yc)² = r², 극좌표 x = xc + r cosθ, y = yc + r sinθ.
  • 브레즌햄: 제곱근 삼각함수 없이 정수 연산만. 45° ≤ θ ≤ 90° 구간(1/8)만 계산하고 나머지는 대칭으로.
  • 시작점 (xc, yc + r), x를 1씩 늘리면 다음 점은 (x+1, y) 또는 (x+1, y−1).
  • 초기값 p1 = 3 − 2r
  • p < 0 → (x+1, y), p += 4x + 6
  • p ≥ 0 → (x+1, y−1), p += 4(x − y) + 10 (x, y는 현재 점)
  • x ≥ y가 되면 1/8 구간 끝.

다각형 내부 판단 규칙 출제

홀짝 규칙 (Even-Odd)접기 횟수 규칙 (Non-Zero Winding)
보는 것몇 번 교차했나어느 방향으로 교차했나
방법점에서 한쪽으로 주사선을 그어 경계와 교차한 횟수를 셈에지 방향을 꼭짓점 순서로 정하고, 아래 방향 에지와 교차하면 +1, 위 방향이면 −1 해서 합을 구함
판단홀수 → 내부, 짝수 → 외부합 ≠ 0 → 내부, 합 = 0 → 외부
특징구현이 간단조금 복잡하지만 에지 방향으로 내부 외부를 자유롭게 지정, 정교한 드로잉 소프트웨어에서 사용

별 모양처럼 겹친 도형의 가운데 오각형: 홀짝 규칙은 2번 교차라 외부, 접기 횟수 규칙은 같은 방향 2번이라 합 2로 내부. 결과가 다르게 나오는 대표 예

그림으로 보기 1 별 모양

판단하고 싶은 점(검은 점)에서 오른쪽으로 빨간 선을 쭉 긋고, 테두리와 만나는 곳(빨간 점)을 봐요. 별은 꼭짓점을 한 칸씩 건너뛰며 한 붓으로 그린 도형이라 테두리끼리 겹쳐요. 회색 화살표는 그린 순서 방향이에요.

그림으로 보기 2 사각형 안에 사각형

접기 횟수 규칙은 방향을 보니까, 안쪽 사각형을 어느 방향으로 그렸느냐에 따라 구멍이 생기기도 하고 안 생기기도 해요. 홀짝 규칙은 방향과 상관없이 2번 만나니까 항상 구멍이에요.

시험에서 푸는 순서

  1. 판단할 점에서 한쪽(보통 오른쪽)으로 수평선을 긋는다.
  2. 홀짝 규칙: 테두리와 만나는 점을 센다. 홀수면 내부, 짝수면 외부.
  3. 접기 횟수 규칙: 만나는 변마다 방향을 본다. 아래로 가는 변 +1, 위로 가는 변 −1. 다 더해서 0이 아니면 내부, 0이면 외부.

+1 −1 부호는 반대로 잡아도 돼요. 같은 방향끼리는 더해지고 반대 방향끼리는 지워진다는 것만 맞으면 판단 결과는 같아요.

영역 채우기 다각형 알고리즘

  • 영역 = 같은 색의 이웃 픽셀 집합. 4방향 연결, 8방향 연결. 경계가 8방향이면 내부는 4방향, 경계가 4방향이면 내부는 8방향으로 채운다.
  • 시드 채우기: 내부 한 점(시드)에서 이웃으로 퍼짐, 재귀 사용, 페인팅 프로그램.
    • Flood Fill: 기존 영역 색과 같은 색이면 채우고 계속
    • Boundary Fill: 경계색을 만나면 멈춤, 경계색도 채우기 색도 아니면 채움
  • 다각형 주사 변환(주사선 채우기): 주사선마다 다각형 내부 구간을 구해 칠함, 벡터 그리기 소프트웨어.
  • y-x 주사선 알고리즘: 에지를 작은 y 순서로 정렬한 EL(Edge List), 현재 주사선과 만나는 에지만 모은 AEL(Active Edge List). 매 주사선마다 끝난 에지(yb < yk)는 AEL에서 빼고, 시작하는 에지(ya = yk)는 EL에서 AEL로 옮긴 뒤, 교차점 x를 정렬해 두 개씩 짝지어 그 사이를 칠한다. 일관성(coherence) 덕분에 효율적.

앨리어싱과 안티앨리어싱 출제

앨리어싱 = 계단 현상(jaggies). 아날로그 그림을 디지털로 바꿀 때 생기는 샘플링 오차 때문. 저해상도에서 두드러진다

  • 증상: 경계가 들쭉날쭉하고, 선이 움직이면 위치가 튀어 보임.
  • 안티앨리어싱: 경계가 부드럽게 보이게 하는 기법. 컬러나 회색조 장치에서 가능.
    • 해상도를 높인다 → 물리적 한계
    • 경계 픽셀에서 물체 색과 배경 색을 혼합해서 그린다 → 선, 다각형 채우기, 문자 생성에 적용

합성 변환 순서 출제

P' = Mn ··· M2 M1 P. 먼저 하는 변환이 오른쪽, 점에 가까운 쪽부터 적용

  • 임의의 점 (x0, y0) 기준 회전: T(x0, y0) · R(θ) · T(−x0, −y0). 기준점을 원점으로 옮기고, 돌리고, 되돌림.
  • 임의의 점 기준 신축: T(x0, y0) · S(sx, sy) · T(−x0, −y0).
  • 같은 종류 연속: T끼리는 이동량 더하기, S끼리는 배율 곱하기, R끼리는 각도 더하기.
  • 행렬 곱은 결합법칙 O, 교환법칙 X (A·B ≠ B·A). 그래서 순서가 바뀌면 결과가 달라짐.

계산 문제가 나오기 좋은 단원

뷰잉 파이프라인, 윈도우와 뷰포트 출제 뷰포트 계산

모델 좌표계→월드 좌표계→뷰포트 좌표계→정규 좌표계→장치 좌표계
  • 윈도우: 표시하려고 선택한 세계 좌표 영역. "무엇을 보여줄지".
  • 뷰포트: 윈도우가 사상되는 출력 장치 영역. "어디에 보여줄지".
  • 효과: Zooming(확대 축소), Panning(보여주는 영역 평행 이동), Multi viewport(여러 화면).

xv = xvL + (xw − xwL)·sx, sx = (xvR − xvL) / (xwR − xwL)
yv = yvB + (yw − ywB)·sy, sy = (yvT − yvB) / (ywT − ywB)

기호 읽는 법: w는 윈도우, v는 뷰포트. 끝 글자 L 왼쪽(Left), R 오른쪽(Right), B 아래(Bottom), T 위(Top)

클리핑과 점 클리핑

  • 클리핑: 출력 영역 밖의 객체나 그 일부를 제거.
  • 월드 좌표 클리핑: 윈도우 밖을 먼저 지우고 안쪽만 뷰포트로. 뷰포트 클리핑: 전부 매핑한 뒤 뷰포트 밖을 지움. 결과 화면은 같다.
  • 점 P(x, y)는 xL ≤ x ≤ xR 이고 yB ≤ y ≤ yT이면 그린다.

교차점 (m = (y2 − y1) / (x2 − x1))

Liang-Barsky 선 클리핑 ★ 출제 클리핑

  • x = x1 + dx·u, y = y1 + dy·u (dx = x2 − x1, dy = y2 − y1). u = 0이면 P1, u = 1이면 P2.
  • 조건 u·pk ≤ qk, k = 1~4:

  • pk < 0: 밖 → 안으로 들어감. ustart = max(0, qk/pk)
  • pk > 0: 안 → 밖으로 나감. uend = min(1, qk/pk)

조명 모델이란 출제 광원과 물체 색 밝기

물체의 한 점이 어떤 색과 밝기로 보일지 계산하는 모델

  • 영향 요소: 광원의 특성(색, 세기), 광원의 위치(방향, 거리), 물체의 특성(고유색, 반사 특성, 광택), 관찰자의 위치(특히 거울반사).
  • 표면에서: 흡수, 반사(산란, 거울), 굴절 또는 투과(투명 물체).
  • 주변 조명(Ambient): 여러 방향 간접광 단순화, 위치와 방향 상관없이 기본 밝기, 완전히 어두워지는 것 방지.
  • 점광원: 한 위치에 있는 광원(전구, 손전등). 이상적으로 거리의 제곱에 반비례.

산란반사 공식 ★

주변 조명 I = Ka·Ia (0 < Ka < 1)

  • Ia: 주변 조명 밝기, Ka: 주변 조명 반사 계수(물질마다 다름).
  • 램버트 코사인 법칙: 표면이 받는 빛의 양은 cosθ에 비례. cosθ = N·L (N 법선, L 표면에서 광원 방향, 둘 다 단위벡터).
  • 정면으로 향하면 가장 밝고, 비스듬하면 어두움.

점광원 산란 I = (Ip / d)·Kd·(N·L)
Lambert 조명 모델 I = Ka·Ia + (Ip / d)·Kd·(N·L)

구현할 땐 뒷면에서 N·L < 0이 될 수 있어서 max(0, N·L).

예) N = (0, 1, 0), L = (0.6, 0.8, 0), Ip / d = 1, Kd = 0.5, Ka·Ia = 0.1
N·L = 0·0.6 + 1·0.8 + 0·0 = 0.8 (θ ≈ 36.9°)
I = 0.1 + 1·0.5·0.8 = 0.5
L이 (0, 1, 0)으로 정면이면 N·L = 1 → I = 0.6, 옆 (1, 0, 0)이면 N·L = 0 → I = 0.1 (주변광만)

숫자 예제는 공식 확인용으로 만든 값이에요.

거울반사와 Phong 조명 모델 ★

  • L 빛의 입사 방향, N 법선, R 반사된 빛의 방향, V 표면에서 관찰자 방향, Φ는 V와 R 사이 각.
  • Φ가 0°에 가까울수록(관찰자가 반사 방향에 가까울수록) 강하다.
  • 반짝이는 표면일수록 반사 범위가 좁다.

Phong 거울반사 I = (Ip / d)·Ks·cosⁿΦ = (Ip / d)·Ks·(V·R)ⁿ

  • Ks: 거울반사 계수. 반짝일수록 크다.
  • n: 광택 정도. 광택 많으면 n이 크고, 없으면 작다. cosΦ가 0~1이라 n이 크면 값이 급격히 작아져 하이라이트가 좁아짐.
  • 구현할 땐 max(0, V·R)ⁿ.
예) V·R = 0.8일 때 n = 8 → 0.8⁸ ≈ 0.168, n = 256 → 거의 0. 광택이 크면 조금만 벗어나도 하이라이트가 사라짐

Phong 조명 모델 I = Ka·Ia + (Ip / d)·[Kd(N·L) + Ks(V·R)ⁿ]

  • 광원이 멀면 N·L이 표면 위치와 상관없이 일정. 관측자가 멀면 V·R이 일정.

광선추적법 (Ray Tracing)

  • 빛이 물체에 닿아 일부 반사, 일부 굴절. 그 빛이 또 반사, 굴절. 투영면 각 픽셀에 도달하는 빛을 모두 더한다.

  • 은면 제거와 그림자를 동시에 처리. 결과는 매우 사실적이지만 계산 시간이 많다.

윈도우 = 무엇을 보여줄지(세계 좌표 영역), 뷰포트 = 어디에 보여줄지(장치 영역)

Cohen-Sutherland에서 양 끝 코드 AND가 0이 아니면?

둘 다 같은 쪽 바깥이라 완전히 밖, 버림

Liang-Barsky에서 pk < 0이면 무엇을 갱신?

ustart = max(ustart, qk/pk). pk > 0이면 uend = min(uend, qk/pk)
